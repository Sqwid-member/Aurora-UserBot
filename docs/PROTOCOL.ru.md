# Протокол плагинов Aurora

Версия протокола: **1**

Плагин Aurora — это независимый исполняемый файл. Он общается с ядром Aurora
через `stdin`/`stdout`, используя построчный JSON-RPC 2.0 (newline-delimited JSON).
Никаких общих динамических библиотек (`dlopen`), никакого жесткого ABI.

Плагин можно написать на Go, Python, Node.js, Lua, Rust, C или любом другом языке, поддерживающем работу со стандартными потоками ввода/вывода.

---

## 1. Транспорт

```
Ядро  --write-->  stdin плагина      (запросы и уведомления)
Ядро  <--read---  stdout плагина     (ответы и запросы плагина)
Ядро  <--read---  stderr плагина     (логи плагина, перехватываемые ядром)
```

* **Один JSON-объект на строку**, заканчивающуюся символом `\n`.
* Максимальный размер строки — 8 МБ.
* **Никогда не выводите в `stdout` произвольный текст**: `stdout` зарезервирован только под протокол JSON-RPC. Логи следует писать в `stderr`.
* Обрыв `stdin`/`stdout` означает завершение работы ядра: плагин обязан завершить процесс.

---

## 2. Формат сообщений

### Запрос
```json
{"jsonrpc":"2.0","method":"tg.send","params":{"peer":"me","text":"Привет"},"id":1}
```

### Успешный ответ
```json
{"jsonrpc":"2.0","id":1,"result":{"id":42,"peer_id":1234}}
```

### Ошибка
```json
{"jsonrpc":"2.0","id":1,"error":{"code":-32001,"message":"недостаточно прав"}}
```

---

## 3. Жизненный цикл

1. **`plugin.hello`**:
   Ядро запускает плагин и передает `plugin.hello`. Плагин подтверждает готовность:
   ```json
   {"jsonrpc":"2.0","id":1,"result":{"ok":true}}
   ```
2. **`plugin.load`**:
   Ядро сообщает об успешной инициализации окружения.
3. **`plugin.unload`**:
   Отправляется перед штатным завершением работы плагина для освобождения ресурсов.
