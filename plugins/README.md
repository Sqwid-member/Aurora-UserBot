# Приклади плагінів Aurora

Кожен каталог — повністю робочий плагін. Скопіюйте будь-який у
`~/.local/share/aurora/plugins/` або встановіть через панель
(вкладка «Плагіни» → «Встановити»).

| Каталог | Мова | Ритуал | Показує |
|---------|------|--------|---------|
| [`hello/`](hello) | Go + офіційний SDK | `make examples` | повний життєвий цикл, команди, лічильники |
| [`echo/`](echo) | Python | нічого | мінімальний плагін на ~40 рядків |
| [`pulse/`](pulse) | Lua | нічого | власний JSON-кодек, моніторинг, тости |
| [`autoaway/`](autoaway) | Node.js | нічого | таймери, стейт, «сторінки» коду |

## Вбудовані плагіни

Живуть тут же, ставляться разом з ядром. Python, тільки стандартна
бібліотека, без мережі (крім `weather` — він ходить через шлюз
`http.request` з дозволом `net`):

| Каталог | Команда | Що робить |
|---------|---------|-----------|
| [`ping/`](ping) | `/ping` | Понг + аптайм плагіна |
| [`calc/`](calc) | `/calc 2 + 2 * 2` | Безпечний калькулятор (AST, не eval), точність у налаштуваннях |
| [`remind/`](remind) | `/remind 10m текст` | Нагадування таймером у той самий чат (s/m/h/d) |
| [`notes/`](notes) | `/note save/get/list/del` | Особистий нотатник у сховищі ядра |
| [`weather/`](weather) | `/weather [місто]` | Погода через wttr.in, місто за замовчуванням у налаштуваннях |
| [`id/`](id) | `/id` | ID чату, повідомлення й відправника |

Покриття протокол-тестами: `python3 plugins/smoke_test.py` (рукостискання,
команди, KV, HTTP-шлюз, таймер доставки).

## Запуск уручну

Плагін можна запустити й без ядра — він просто побачить EOF на stdin і
завершиться. Але щоб побачити справжню поведінку, підніміть ядро:

```console
$ aurora plugins
$ aurora plugin restart echo
$ aurora plugin remove echo
```

## Налагодження

Найпростіший спосіб — дивитися логи плагіна в панелі (вкладка «Логи»)
або в терміналі:

```console
$ aurora run 2>&1 | grep 'plugin:echo'
```

Плагін пише в `stderr`, ядро перехоплює і додає scope `plugin:<ім'я>`.
Помилки, які ви бачите в панелі в картці плагіна, — це те, що плагін
повернув у `plugin.hello`/`plugin.load`, плюс код виходу процесу.

Щоб підставити свій власний каталог під час розробки:

```console
$ ln -s ~/dev/aurora-plugins/myplug ~/.local/share/aurora/plugins/myplug
```

## Як писати свій

1. Створіть каталог, покладіть туди `aurora.plugin.json`.
2. Реалізуйте обробку `plugin.hello` і `plugin.load` — це обов'язково.
3. Підпишіться на потрібні події в `events` і попросіть лише ті дозволи,
   які реально використовуєте.
4. Перевірте маніфест: `aurora plugin start <ім'я>` покаже помилку
   валідації, якщо щось не так.
