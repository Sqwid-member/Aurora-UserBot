# Aurora 🌌

> **Language / Мова / Язык:** [English](README.md) • [Українська](README.uk.md) • **Русский**

Модульный Telegram **юзербот** на Go. Один статический бинарник, который работает
везде, где работает Go — в том числе **прямо в Termux на телефоне**. Плагины
пишутся на любом языке. Управляется через локальную веб-панель.

```
┌──────────────────────────────────────────────────────────────┐
│  aurora (один бинарник, ~12 МБ, CGO отключен)                │
│                                                              │
│   ┌──────────┐  JSON-RPC  ┌──────────────┐  stdio  ┌───────┐ │
│   │   MTProto│──(stdio)──▶│плагин-менеджер│◀────────│ плагин│ │
│   │  (gotd)  │◀──────────│  + лимиты     │────────▶│  .go  │ │
│   └──────────┘   события  └──────────────┘         │  .py  │ │
│        │                                             │  .lua │ │
│        │                                             │  .mjs │ │
│   ┌────▼─────┐   HTTP/SSE   ┌────────────────────┐  └───────┘ │
│   │  панель  │◀─────────────│ 127.0.0.1:8420     │            │
│   └──────────┘              └────────────────────┘            │
└──────────────────────────────────────────────────────────────┘
```

## Ключевые особенности

| Требование | Решение |
|---|---|
| **Максимальная производительность** | Go, `CGO_ENABLED=0`, без тяжелых фреймворков. Разбор апдейтов не делает сетевых вызовов — только кэш имен и map-структуры в памяти. Очередь событий ограничена, доставка неблокирующая. |
| **Минимум оперативной памяти** | `debug.SetMemoryLimit` по умолчанию 96 МБ, минимальное число горутин, кольцевой буфер логов, `kv` — JSON в памяти, панель — один HTML без CDN. `RLIMIT_DATA` на каждый плагин (не `RLIMIT_AS` — подробности в [docs/PROTOCOL.ru.md](docs/PROTOCOL.ru.md)). |
| **Модульность** | Ядро ничего не знает о конкретных плагинах. Плагин — обычный исполняемый файл, общающийся через JSON-RPC, с манифестом, правами, лимитами и жизненным циклом. |
| **Плагины на любом языке** | Go SDK (без зависимостей), Python, Node.js, Lua — примеры включены в репозиторий. Протокол — построчный JSON, поэтому подходит любой язык. |
| **Оптимизация под Termux** | Устанавливается за секунды из готового бинарника в `$PREFIX/bin`, фоновый режим `aurora start` с `termux-wake-lock`, интерактивный `aurora setup`, автоматический запуск веб-панели. |
| **Простая установка** | Одна команда через curl или `make install`. Никаких внешних баз данных и системных демонов. |
| **Локальная веб-панель** | Встроенный SPA: статус, плагины, вход, мультиаккаунт, чат, логи, настройки. Токен в cookie, слушает только loopback. |

## Установка в Termux

```console
$ pkg install curl
$ curl -fsSL https://raw.githubusercontent.com/Sqwid-member/Aurora-UserBot/main/scripts/install.sh | bash
```

Скрипт:
1. Определяет платформу (`android/arm64`, `linux/armv7`, `linux/amd64`, `darwin/*`).
2. Запрашивает GitHub Releases и **скачивает готовый бинарник** — компилировать на телефоне ничего не требуется.
3. Помещает бинарник в `$PREFIX/bin/aurora` и настраивает алиасы (`a`).
4. Настраивает базовые плагины и запускает сервис.

### Linux / macOS

```console
$ curl -fsSL https://raw.githubusercontent.com/Sqwid-member/Aurora-UserBot/main/scripts/install.sh | bash
```

Устанавливает в `~/bin/aurora`.

### Готовые бинарники

Скачивайте напрямую со страницы [GitHub Releases](https://github.com/Sqwid-member/Aurora-UserBot/releases/latest):

* `aurora-arm64` — Termux / Android aarch64 & Linux ARM64
* `aurora-amd64` — Linux x86_64
* `aurora-linux-arm.tar.gz` — Termux 32-bit ARM (armv7)
* `aurora-darwin-arm64` — Apple Silicon (M1/M2/M3/M4)
* `aurora-darwin-amd64` — Intel macOS

## Первый запуск и авторизация

Запустите консольный центр управления:

```console
$ aurora
# или краткий алиас:
$ a
```

### Варианты входа:
1. **Вход по QR в один тап на этом же телефоне** (Рекомендуется для Termux):
   * Выберите `Вхід по QR`.
   * Нажмите `Відкрити в Telegram` на этом же телефоне.
   * Официальный Telegram запросит подтверждение входа. Номер и SMS не нужны.
2. **Вход по номеру телефона**:
   * Введите номер в международном формате (`+380...` / `+7...`).
   * Введите полученный код подтверждения и 2FA пароль (если включен).
3. **Импорт сессии**:
   * Импортируйте строку StringSession (Telethon / Pyrogram) прямо в веб-панели.

### Управление фоновым сервисом

```console
$ a start    # Запустить службу в фоне
$ a stop     # Остановить службу
$ a restart  # Перезапустить
$ a status   # Статус службы и Telegram
$ a logs -f  # Живой просмотр логов
$ a update   # Автоматическое обновление до актуальной версии
```

## Веб-панель управления

Локальный веб-интерфейс доступен по адресу:
```
http://127.0.0.1:8420/?token=<ваш-токен>
```
Чтобы открыть панель автоматически в браузере:
```console
$ a web
```

## Справочник CLI

```console
$ aurora run                          # ядро: Telegram + плагины + панель
$ aurora login                        # интерактивный вход (номер → код → 2FA)
$ aurora login qr                     # вход тапом на этом же телефоне
$ aurora login web                    # открыть веб-панель для входа
$ aurora panel                        # напечатать ссылку панели с токеном
$ aurora send [--silent] [--no-preview] @user "привет"
$ aurora commands                     # список команд плагинов
$ aurora command <имя> [текст]        # выполнить команду плагина
$ aurora accounts                     # список Telegram-аккаунтов
$ aurora accounts switch <id>         # переключить активный аккаунт
$ aurora sessions                     # список активных сессий Telegram
$ aurora sessions kill <hash>         # завершить сессию
$ aurora profile                      # профиль (имя, юзернейм, био)
$ aurora gc                           # сборка мусора в ядре
$ aurora snoop [n]                  # последние удалённые/изменённые сообщения
$ aurora plugins                      # список плагинов
$ aurora plugin start|stop|restart <имя>
$ aurora plugin install <git-url> [имя]
$ aurora plugin remove <имя>
$ aurora plugin settings <имя> [к=зн ...]  # пустое значение = сброс ключа
$ aurora plugin settings <имя> reset        # сбросить всё к дефолтам
$ aurora session                      # информация о локальной сессии
$ aurora session export               # StringSession (Telethon/Pyrogram)
$ aurora session import "1BVts…"      # импорт без SMS
$ aurora session import-web <JSON|@файл> [--dc N]  # экспорт Telegram Web
$ aurora backup [файл]                # связка конфиг+сессии для переезда
$ aurora restore <файл>               # восстановить (ядро остановлено)
$ aurora device [--save]              # слепок устройства
$ aurora config                       # конфиг (секреты скрыты) + проверка
$ aurora doctor                       # проверка окружения
$ aurora status                       # живой статус демона/сессии/RAM
$ aurora logs                         # живой хвост логов
$ aurora update                       # самообновление до последнего релиза
$ aurora logout                       # закрыть сессию Telegram
```
